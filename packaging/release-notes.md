# WebScraper 1.0.0

- Český Windows instalátor a spouštění ikonou bez Pythonu a BAT skriptů.
- Přibalené Chromium pro WLW.de a 11880.com.
- Oddělená uživatelská data zachovaná při aktualizaci a odinstalaci.
- Kontrola nových verzí z GitHub Releases a instalace po potvrzení uživatelem.
- Bezpečné kopírování nastavení a uložených běhů z původní složky.

Koncept vydání: stabilní zveřejnění vyžaduje dokončení checklistu v docs/DISTRIBUCE.md. První vydání nemá digitální podpis vydavatele.
